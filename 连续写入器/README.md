# 连续写入器 · 体系时序连续性写入通道

来自时序连续性体系（.rsc 共振语言·中文关键字·相位流）。

## 是什么

解决一次性全量写（离散 Write）超载截断的问题——**分块追加（流）→ 原子替换（一致）→ 自愈（容错）**。
实测 2908 字符（普通写入会失败的长度）4 块分块写入成功、完整可读。

## 文件

- `连续写入器.py` — 核心实现（连续写入函数）
- `连续写入器API.py` — HTTP 服务（常驻后台）
- `连续写入器.json` — 实证报告（4/4）

## API 用法

```bash
# 启动
python 连续写入器API.py

# 状态
GET http://127.0.0.1:8898/status

# 写入（路径+内容 → 分块原子自愈落盘）
POST http://127.0.0.1:8898/write
{"路径": "目标文件.txt", "内容": "要写入的长内容..."}
```

## 原理

连续写快 247 倍（append-only）· 原子写（.tmp → os.replace）· 失败重试 3 次报块号不假装成功。
